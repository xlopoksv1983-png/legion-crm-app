# Legion CRM — застосунок (PWA)

Каркас застосунку для тренера і його клієнтів. Один застосунок, дві ролі:
тренер бачить CRM з усіма клієнтами, клієнт бачить лише свій особистий кабінет.

Працює як звичайний вебсайт, але встановлюється на телефон (Android і iPhone)
як іконка на головному екрані — без App Store і Google Play.

## Що вже зроблено (v0.2)

- Вхід в акаунт (email + пароль)
- Ролі: тренер / помічник / клієнт (розмежування доступу на рівні бази даних)
- **Тренер:** головна (лічильники, прострочені звіти), список клієнтів з пошуком
  і створенням нового клієнта, картка клієнта з вкладками:
  огляд, **програма тренувань** (додавання днів і вправ з планом сетів/повторів/ваги/RIR),
  тренування (журнал), харчування (журнал), заміри (журнал + форма),
  **анкета** (перегляд), **фото** (перегляд галереї)
- **Клієнт:** власний кабінет — сьогоднішнє тренування з програми тренера,
  внести харчування, внести заміри, залишити відгук про самопочуття,
  **заповнити анкету**, **завантажити фото** (профіль і прогрес, з ракурсами)
- Завантаження фото працює через Supabase Storage (приватний bucket,
  тренер бачить усі фото, клієнт — лише свої)
- База даних: клієнти, вправи, продукти, тренування (план + факт), кардіо,
  заміри, харчування, фото, анкета — з правами доступу (RLS)

## Що ще можна доробити далі

- Редагування довідників (вправи/продукти) прямо в застосунку
- Графіки прогресу (вага, обхвати) — дані вже є, треба додати візуалізацію
- Порівняння план/факт у тренуваннях з рекомендаціями по прогресії ваги
- Push-сповіщення про наближення дати звіту

Ці частини найзручніше доробляти в Claude Code — там можна одразу
запускати застосунок, бачити зміни наживо і тестувати на телефоні.

## Крок 1. Створити безкоштовний бекенд (Supabase)

1. Зареєструйся на https://supabase.com (можна через Google/GitHub)
2. Створи новий проєкт (New Project) — обери будь-який регіон, придумай пароль до бази
3. Зачекай ~2 хвилини, поки проєкт розгорнеться
4. Відкрий **SQL Editor** → **New query**
5. Відкрий файл `schema/schema.sql` з цього проєкту, скопіюй увесь вміст, встав і натисни **Run**
   — це створить всі таблиці, права доступу і додасть базові довідники/приклади вправ і продуктів
6. Відкрий **Project Settings → API** — там знайдеш `Project URL` і `anon public key`,
   вони знадобляться на наступному кроці

## Крок 2. Налаштувати застосунок локально

Знадобиться встановлений [Node.js](https://nodejs.org) (версія 18+).

```bash
cd legion-crm-app
npm install
cp .env.example .env
```

Відкрий `.env` і встав свої значення з Supabase (Project URL і anon key).

```bash
npm run dev
```

Застосунок відкриється на `http://localhost:5173`. Поки що акаунтів нема —
їх треба створити (крок 3).

## Крок 3. Створити перший акаунт тренера

1. У Supabase зайди в **Authentication → Users → Add user** — введи email і пароль тренера
2. Скопіюй **User UID** створеного користувача
3. У **SQL Editor** виконай (підстав свій UID і ім'я):

```sql
insert into profiles (id, role, full_name)
values ('ВСТАВ_СЮДИ_UID', 'trainer', 'Ім'я Тренера');
```

4. Тепер можна залогінитись в застосунку цим email/паролем — відкриється CRM тренера

### Додавання клієнта (поки що через SQL, інтерфейс — наступний крок)

```sql
insert into clients (full_name, phone, telegram, goal, status, program)
values ('Ім'я Клієнта', '+380...', '@telegram', 'Похудение', 'Активный', 'Full Body');
```

Якщо клієнт теж має заходити у свій кабінет — так само створи йому користувача
в Authentication, профіль з роллю `client`, і онови його рядок у `clients`,
вказавши `user_id` = UID цього користувача.

## Крок 4. Викласти застосунок онлайн (безкоштовно)

Найпростіше — [Vercel](https://vercel.com):

1. Заведи акаунт на vercel.com (через GitHub)
2. Заливаєш цей проєкт у свій GitHub-репозиторій
3. У Vercel: **New Project** → обираєш цей репозиторій → у налаштуваннях
   додаєш ті самі змінні з `.env` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`)
4. Deploy — отримаєш посилання типу `legion-crm.vercel.app`

Це посилання відкриваєш на телефоні (Android чи iPhone) і додаєш на головний
екран через меню браузера ("Додати на головний екран" / "Add to Home Screen") —
з'явиться іконка, застосунок відкривається на весь екран, без адресного рядка.

## Технології

- **Frontend:** React + Vite, PWA (vite-plugin-pwa)
- **Backend:** Supabase (Postgres, Auth, Storage) — безкоштовний тариф
- **Хостинг:** Vercel — безкоштовний тариф

## Структура проєкту

```
schema/schema.sql          — вся структура бази даних
src/lib/supabase.js        — підключення до Supabase
src/lib/AuthContext.jsx    — авторизація і роль користувача
src/App.jsx                — маршрутизація (тренер / клієнт)
src/components/Layout.jsx  — верхня навігація
src/screens/               — екрани застосунку
```
